Bank Customer Churn Prediction

This is a beginner Machine Learning project where I built a model to predict whether a bank customer will churn (leave the bank) or stay.

About the Project

As a beginner in Machine Learning, I created this project to practice building a complete ML workflow using Python and scikit-learn.

Model Used
	•	Logistic Regression

Libraries Used
	•	Pandas
	•	NumPy
	•	Scikit-learn

Steps Performed
	1.	Data preprocessing and encoding
	2.	Feature scaling using StandardScaler
	3.	Train-test split
	4.	Training a Logistic Regression model
	5.	Evaluating the model using accuracy and confusion matrix

Result

The model achieved ~79% accuracy on the test dataset.

File
	•	BankCustomerChurn_SCIKIT.ipynb – Jupyter notebook containing the implementation.
